# D Loop 3D — Filament Studio
Private stock tracker for Anycubic Kobra 3 and Creality SPARKX i7. This is an independently implemented focused application, not a full fork of FilaMan.

Cloudflare D1 stores spool records, per-colour manual print usage, measured corrections, printer slot labels and event history. Optimistic revisions prevent silent concurrent edits. Export and restore JSON backups from Backup & help.

Printer telemetry, automatic NFC reading and hardware scale integrations are not connected. Slot labels are organisational. Kobra slot labels do not imply an ACE unit is installed. Weight balances are estimates until reweighed.
